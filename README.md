# 🦸‍♂️ Marvel Heroes Cards

> Projeto front-end interativo que exibe cards de heróis da Marvel com sistema de XP e nível.

---

## 📌 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar lógica de programação e desenvolvimento front-end.

A aplicação apresenta cards de heróis da Marvel, onde cada personagem possui uma quantidade de XP. Ao clicar no card, o sistema calcula e exibe o nível do herói com base no seu XP.

---

## 🚀 Funcionalidades

- Exibição de cards de heróis
- Sistema de XP individual para cada personagem
- Cálculo de nível baseado no XP
- Interação ao clicar nos cards
- Interface simples e responsiva

---

## 🧠 Lógica aplicada

O projeto utiliza conceitos de lógica de programação para:

- Manipulação de eventos (click)
- Atualização dinâmica de informações na tela
- Associação entre dados (XP) e resultado (nível)

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
